Shaders + Animación

Un curso para entender la GPU, GLSL y la animación con JavaScript de verdad: cada llamada, cada línea y cada comportamiento raro.

Del HTML mínimo a un proyecto final que junta JavaScript y shaders, pasando por el event loop, los TypedArrays, la animación, el pipeline de la GPU, una GPU de juguete escrita en Python, WebGL2 crudo, GLSL a fondo y el raymarching. Cada lección trae ejemplos resueltos, ejercicios con solución y editores en vivo.
